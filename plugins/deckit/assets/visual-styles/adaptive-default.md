# Visual Style: adaptive-default

## Intent

Derive a coherent visual system from the deck's audience, thesis, source material, and slide archetypes. This is a deliberate adaptive style, not permission to leave visual direction vague.

## Global prompt contract

- Fix one palette, one typography direction, one illustration or image treatment, and one spacing system in `prompts/README.md` before writing per-slide prompts.
- Prefer argument-supporting structures such as comparisons, processes, evidence layouts, charts, maps, and timelines.
- Keep text readable at presentation distance and preserve meaningful negative space.
- Use the same visual language across every slide unless the storyboard explicitly motivates a controlled exception.
- Ban decorative-only cinematic backgrounds, pseudo-text, watermarks, logos, and unrelated stock imagery.

## Selection guidance

Use this preset when the user has not requested a named style and no other library style is a clearly better fit. The visual director must still make concrete choices and record them in the prompt pack.
